# Sentinel FAQ Bot
> **Cognitive TF-IDF Intent Matching Chatbot**  

Sentinel FAQ Bot is an advanced, production-grade conversational AI microservice built with **FastAPI** and **NLTK/Scikit-Learn**. It features a premium, spatial glassmorphic UI and real-time inference monitoring.

## 🚀 Key Features

* **Cognitive Semantic Engine:** Uses TF-IDF vectorization and cosine similarity to map user intent to knowledge base answers precisely.
* **Pre-Processing Pipeline:** Implements NLTK-based tokenization, lemmatization, and stop-word removal.
* **Real-time Telemetry:** Exposes latency metrics (ms) and confidence matching scores for every interaction.
* **VisionOS UI Aesthetics:** A beautifully crafted, hardware-accelerated frontend using glassmorphism, Aurora orb ambient backgrounds, bounding micro-animations, and modern typography.
* **Extensible Knowledge Base:** FAQs are stored efficiently and can be dynamically updated via API.

## 🛠 Tech Stack

* **Backend:** Python, FastAPI, Uvicorn, Scikit-Learn, NLTK
* **Frontend:** HTML5, CSS3, TailwindCSS, Vanilla JavaScript
* **Algorithms:** TF-IDF, Cosine Similarity

## ⚙️ Installation & Usage

1. **Install Dependencies**
   Make sure you have Python 3.9+ installed.
   ```bash
   pip install -r requirements.txt
   ```
2. **Start the Neural Engine**
   ```bash
   python main.py
   ```
3. **Access the Interface**
   Open `http://localhost:8002` in your browser.

## 🧪 Evaluation

To run the automated verification script:
```bash
python run_eval.py
```
This tests core NLP processing routes, response accuracy, and API endpoints, outputting a success validation block.
